# SpaceX Falcon 9 Data Science Capstone

Public course project repository. The accompanying report and slides use an educational 90-launch sample (2010–2020). They do **not** demonstrate completed original API scraping, dashboard execution or model evaluation.

## Files
- `Data_Science_Capstone_Presentation.pptx` — editable project slides
- `Data_Science_Capstone_Project_Report.pdf` — report
- `analysis.py` — reproducible summary, charts, and local SQLite database
- `requirements.txt` — Python dependencies

## Run
```bash
pip install -r requirements.txt
python analysis.py
```

## Dataset and credit
Historical dataset from https://github.com/Abhigyan-RA/SpaceX-capstone/blob/main/dataset_part_2.csv (third-party educational source). Data gathering and original notebooks must be added separately for relevant rubric requirements.
